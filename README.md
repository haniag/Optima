## Optima

- Optima is a macOS and iOS app that optimizes your photo library.  
- It automatically scans your library for either photos or videos, and identifies the ones that can be compressed.  
- User can choose compression settings, resize dimensions, and video bitrate.  
- What differentiates Optima is its ability to use Apple's private photos API to set the added date for the new photo/video as the original. This ensures your photo library timeline isn't affected.
- I saved 20GBs in my photo library by running this app!
